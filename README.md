# HTTPSrvLauncher

[RU](README.md) | [EN](README.en.md)      

`HTTPSrvLauncher` — это легковесный инструмент автоматизации (Windows-служба), который слушает заданные сетевые порты и автоматически запускает оригинальные серверные приложения (например, `TorrServer`, `Ace Stream` или любые другие веб-серверы) только в момент поступления первого входящего запроса.

Это позволяет экономить системные ресурсы (ОЗУ и CPU), не удерживая серверы постоянно запущенными в фоне.

## 🚀 Основные возможности

* **Запуск по требованию (On-Demand):** Сервер спит, пока к нему никто не обращается.
* **Поддержка любых серверов:** Работает с `TorrServer`, медиасерверами и другими CLI-приложениями.
* **Мультипортовость:** Возможность слушать несколько портов для разных утилит.
* **Автозавершение:** Опциональное выключение целевого приложения при отсутствии активности (таймаут).
* **Служба Windows:** Работает в фоновом режиме как стандартный Windows Service.

## 🛠 Установка и управление службой

Проект разработан на **C#**. Вы можете собрать его из исходников или использовать готовый бинарный файл.

Для управления Windows-службой используйте утилиту `sc.exe` в командной строке от имени Администратора:

### Регистрация службы
```cmd
sc create HTTPSrvLauncher binPath= "C:\Path\To\HTTPSrvLauncher.exe" start= auto
ИЛИ
install.cmd
```

### Запуск службы
```cmd
sc start HTTPSrvLauncher
ИЛИ
net start HTTPSrvLauncher
ИЛИ
start.cmd
```

### Остановка службы
```cmd
sc stop HTTPSrvLauncher
ИЛИ
net stop HTTPSrvLauncher
ИЛИ
stop.cmd
```

### Удаление службы
```cmd
sc delete HTTPSrvLauncher
ИЛИ
uninstall.cmd
```

## ⚙️ Настройка (Конфигурация)

Настройка параметров запуска осуществляется через файл конфигурации `HTTPSrvLauncher.json`, расположенный в директории со службой.

Пример файла `HTTPSrvLauncher.json`:

```json
{	
    "8090": {
        "ServerPath": "C:\\DISK4\\TorrServer\\TorrServer-windows-amd64.exe",
		"SendWebRedirect": true,
		"Arguments": "--path \"C:\\DISK4\\TorrServer\""
    }
}
```

## 📖 Принцип работы

После старта Windows-служба `HTTPSrvLauncher` занимает указанные порты. Как только ваш плеер или браузер сделает запрос на `http://localhost:8090`, лаунчер мгновенно запустит целевой процесс (например, `TorrServer`) и перенаправит сетевой трафик.
